# Security Policy

Please do not report security-sensitive details in public issues.

RepoGuardian treats repository content, issue text, comments, pull request descriptions, README files, and code as untrusted evidence. External write actions are human-gated by policy.

Do not commit API keys, GitHub tokens, database credentials, webhook secrets, private keys, private repository datasets, or model weights.

For private repositories, cloud model providers are disabled unless explicitly allowed by configuration.
